# La-pauta--Ap550-pro
La Pauta AP550 Pro es un ecualizador de 3 bandas inspirado en la consola API 550A. Incluye HF, MF y LF con frecuencias y ganancias por pasos, shelf o campana, filtro, polaridad, saturación analógica, medidores VU y más de 35 presets. VST3 y Standalone, con interfaz en gris plateado.
